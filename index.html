flutter_soft_keyboard Flutter MIT

A fully customizable virtual keyboard widget built using a 2D array layout. Ideal for PIN pads, custom alphanumeric inputs, and any app requiring a non-system keyboard.

Platform support
Android iOS Linux macOS Web Windows
Installation
yaml 
dependencies:
  flutter_soft_keyboard: ^latest
Basic usage
dart 
// 1. Create a controller
final keyboardController = KeyboardInputController();

// 2. Listen to key events
keyboardController.setKeyListener((lastKey, enteredText) {
  print('Last key: $lastKey');
  print('Full text: $enteredText');
});

// 3. Define a 2D key layout
final keyLayout = [
  [VirtualKey(text: '1'), VirtualKey(text: '2'), VirtualKey(text: '3')],
  [VirtualKey(text: '4'), VirtualKey(text: '5'), VirtualKey(text: '6')],
  [VirtualKey(text: '7'), VirtualKey(text: '8'), VirtualKey(text: '9')],
];

// 4. Use the widget
SoftKeyboardWidget(
  width: 400,
  height: 300,
  columnSpacing: 4,
  rowSpacing: 4,
  keyLayout: keyLayout,
  keyboardInputController: keyboardController,
)
Key features
Define any keyboard layout using a simple 2D array
Real-time key listener with last key and full entered text
Customizable column and row spacing
Explicit width/height control for precise sizing
Integrates with ripple_container for tap feedback
Constructor parameters
Parameter Type Description
keyLayoutrequiredList<List<VirtualKey>>2D array defining the keyboard structure
keyboardInputControllerrequiredKeyboardInputControllerController for listening to input events
widthdoubleTotal width of the keyboard widget
heightdoubleTotal height of the keyboard widget
columnSpacingdoubleHorizontal spacing between keys (default: 4)
rowSpacingdoubleVertical spacing between rows (default: 4)
Lifecycle
dart 
@override
void dispose() {
  keyboardController.dispose(); // Always dispose!
  super.dispose();
}
ripple_container Flutter MIT

A versatile Box widget that wraps any child with a customizable ripple (ink splash) effect. Acts as a fully styleable touchable container — a powerful alternative to bare GestureDetector.

Installation
yaml 
dependencies:
  ripple_container: ^latest
Basic usage
dart 
RippleContainer(
  width: 200,
  height: 100,
  backgroundColor: Colors.blueAccent,
  margin: const EdgeInsets.all(10),
  borderRadius: BorderRadius.circular(30),
  splashColor: Colors.amber,
  border: const Border.fromBorderSide(
    BorderSide(color: Colors.grey),
  ),
  boxShadow: [
    BoxShadow(
      color: Colors.black.withOpacity(0.5),
      offset: const Offset(0, 2),
      blurRadius: 10,
    ),
  ],
  onTap: () => print('tapped'),
  onLongPress: () => print('long pressed'),
  child: const Text('Tap me'),
)
Key features
Native Material ripple/splash effect on any container
Full control over background color, border, border radius
Box shadow support for elevation effects
onTap and onLongPress callbacks
Custom splash color for branded interactions
Constructor parameters
ParameterTypeDescription
childrequiredWidgetThe widget placed inside the container
widthdouble?Container width; defaults to parent constraints
heightdouble?Container height; defaults to child height
backgroundColorColor?Background fill color of the container
borderRadiusBorderRadius?Rounded corners applied to container and ripple
splashColorColor?Color of the ripple splash effect
borderBorder?Border drawn around the container
boxShadowList<BoxShadow>?Shadow layers for elevation
marginEdgeInsets?Outer margin around the container
onTapVoidCallback?Called when the container is tapped
onLongPressVoidCallback?Called on long press
size_tailored_text Flutter MIT

Automatically scales text to fit the size of its parent widget. Removes the guesswork from responsive typography — set a target font size and the widget adjusts it to fill the available space.

Installation
yaml 
dependencies:
  size_tailored_text: ^latest
Basic usage
dart 
// Text automatically scales to fit the parent widget
SizedBox(
  width: 200,
  height: 60,
  child: SizeTailoredText(
    text: 'Hello World',
    style: const TextStyle(
      fontSize: 100, // maximum font size
      fontWeight: FontWeight.bold,
    ),
  ),
)
Use case: responsive card title
dart 
LayoutBuilder(
  builder: (context, constraints) {
    return SizeTailoredText(
      text: userName, // dynamic text that could be any length
      style: const TextStyle(fontSize: 24),
    );
  },
)
Key features
Auto-scales font size to fit parent dimensions
Accepts standard TextStyle for full styling control
Ideal for dashboards, cards, and any variable-length text
Cross-platform: Android, iOS, Web, Desktop
project_color_palette Flutter MIT

A bridge between designers and Flutter developers. Converts a project's color definitions from a CSV file into typed Flutter Color objects — eliminating manual hex copy-paste and keeping design tokens in sync.

Installation
yaml 
dependencies:
  project_color_palette: ^latest
CSV format
csv 
# colors.csv
primary,#1A73E8
secondary,#F5F5F5
accent,#FF6D00
error,#B00020
surface,#FFFFFF
Usage
dart 
// Load palette from CSV asset
final palette = await ProjectColorPalette.fromCsv('assets/colors.csv');

// Access colors by name
Container(
  color: palette['primary'],
  child: Text('Brand color'),
)
Key features
Designer-developer collaboration via simple CSV files
Single source of truth for project color tokens
Eliminates manual hex value copy-paste errors
Integrates with existing Flutter theming system
aqlinter Flutter MIT

A curated set of lint rules for Flutter projects. Drop it into your analysis_options.yaml and get a consistent, opinionated code quality baseline across your entire team.

Installation
yaml 
dev_dependencies:
  aqlinter: ^latest
Setup
yaml — analysis_options.yaml 
# analysis_options.yaml — in your project root
include: package:aqlinter/analysis_options.yaml

# Optionally override specific rules below
linter:
  rules:
    prefer_single_quotes: true
Key features
Opinionated, battle-tested rules for Flutter/Dart codebases
One-line include — zero configuration required
Fully overridable on a per-rule basis
Keeps entire team on the same code style
